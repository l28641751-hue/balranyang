# 스토어 설문·신고 답안 (1.0 버전 기준: 광고 없음 · 계정 없음 · 결제 없음)

> 앞으로 결제·광고·온라인 랭킹을 넣으면 아래 답이 달라집니다. 그때 다시 확인하세요.

## Google Play Console
**앱 콘텐츠 → 개인정보처리방침**: 위 방침 주소 입력
**데이터 보안 설문**
- 앱에서 사용자 데이터를 수집하거나 공유하나요? → **아니요**
- (수집·공유 없음이므로 전송 중 암호화/삭제 요청 항목은 해당 없음)
**광고**: 광고 포함 → **아니요**
**앱 액세스**: 모든 기능 제한 없이 이용 가능
**콘텐츠 등급 (IARC 설문)**: 폭력·성적 내용·욕설·도박·약물 모두 **없음**, 사용자 간 소통 없음, 위치 공유 없음, 디지털 구매 없음 → 전체이용가(3+) 예상
**타겟 연령층 (가족 정책 적용 여부)**
- 어린이가 이용할 수 있는 앱이므로 '6~8세, 9~12세'를 포함해 선택하면 **가족용 앱 정책**이 적용됩니다. 이 앱은 광고·데이터 수집이 없어 충족하기 쉽습니다.
- 만 5세 이하를 포함하려면 해당 구간도 선택해야 합니다.
**정부 앱 / 금융 / 건강 / 뉴스 앱**: 모두 아니요
**권한**: 요청하는 위험 권한 없음 (인터넷 권한만 기본 포함)

## App Store Connect
**앱 개인정보 보호(Privacy Nutrition Label)**: "**데이터를 수집하지 않음(Data Not Collected)**"
**연령 등급 설문**: 모든 항목 없음/아니오 → **4+** 예상
**어린이 카테고리(Kids Category) 지원 여부**: 신청 가능(만 5세 이하/6~8/9~11 중 선택). 신청하면 심사 기준이 더 엄격(외부 링크·구매는 보호자 확인 필수)하지만 광고·분석이 없어 문제 없음. 1.0에서는 일반 게임 카테고리로 등록하고 이후 결정해도 됩니다.
**수출 규정(암호화)**: Info.plist에 ITSAppUsesNonExemptEncryption=false 설정됨 → 표준 암호화(HTTPS)만 사용, 면제
**로그인 필요 여부**: 로그인 없음 (심사용 계정 불필요)
**심사 메모(App Review Notes) 제안**: "Offline puzzle game for all ages. No account, no ads, no data collection, no in-app purchases in this version."
